## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/SumitKSinghDev/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Local server will run at `http://localhost:5173/`.

### Production Build

```bash
npm run build
```

The optimized static assets will be output to the `dist/` directory ready for deployment.
